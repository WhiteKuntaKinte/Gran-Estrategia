GRAN ESTRATEGIA — VERSION 0.1.7.6 (DESARROLLO / PASS CHECK)

ABRIR EL PROYECTO
1. Descomprime el ZIP.
2. Abre en Godot 4.7 la carpeta que contiene directamente project.godot.
3. Pulsa F5 para ejecutar.

No busques una subcarpeta con el mismo nombre: el ZIP contiene los archivos del proyecto directamente en su raíz.

CAMBIOS CARTOGRÁFICOS 0.1.7.6
- Reproyección de los 480 territorios actuales a una proyección cilíndrica equivalente ajustada al lienzo 2:1.
- Las provincias, fronteras, costas, etiquetas y datos de selección se generan a partir de la misma geometría reproyectada.
- Las altas latitudes dejan de ocupar una superficie visual desproporcionada respecto a las zonas ecuatoriales.
- Nueva textura oceánica basada en 12 niveles batimétricos, desde 0 hasta 10.000 metros, con transiciones difuminadas y halo costero suave.
- La textura de profundidad aparece al acercarse con el zoom y desaparece en el zoom extremo para evitar pixelación.

ALCANCE
Se conserva el inventario actual de 480 territorios y 177 países. Esta actualización revisa su representación geométrica/proyección; no añade nuevas subdivisiones administrativas ni cambia el número de territorios.

ARCHIVOS PRINCIPALES
- project.godot: configuración de Gran Estrategia 0.1.7.6.
- mapa_principal.tscn: escena inicial.
- MapaPrincipal.gd: controlador, renderizado, HUD y menús.
- datos/: geometría reproyectada, mallas, etiquetas y textura marítima.
- herramientas/construir_mapa.py: genera geometría, fronteras y etiquetas.
- herramientas/construir_profundidad.py: genera la textura de profundidad a partir de Natural Earth.

REGENERAR DATOS
El ZIP incluye todos los datos ya generados. Para reconstruirlos desde el código se necesita Python 3.12 con numpy, scipy, pillow y pyshp, además de Natural Earth 10m Bathymetry 4.1.0 (SRTM Plus). Consultar datos/FUENTES_CARTOGRAFICAS.txt.

VALIDACIÓN
La rama está configurada para validar sintaxis, datos, importación y arranque con Godot 4.7 en GitHub Actions. La validación headless no sustituye la revisión visual dentro de Godot.
