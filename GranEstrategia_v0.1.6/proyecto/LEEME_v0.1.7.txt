GRAN ESTRATEGIA - v0.1.7 (DESARROLLO)

ESTA VERSION ESTA EN LA RAMA:
v0.1.7-development

COMO ABRIR
1. Descarga el ZIP de esta rama desde GitHub.
2. En la carpeta del proyecto, conserva project.godot como copia de seguridad y renombralo a project_0.1.6_backup.godot.
3. Renombra project_0.1.7.godot a project.godot.
4. Abre la carpeta en Godot 4.7 o compatible y ejecuta F5.

CAMBIOS INCLUIDOS EN EL CODIGO 0.1.7
- El menu principal ahora incluye OPCIONES.
- Opciones calcula desde provincias_juego.json la cantidad de paises/soberanias, provincias administrativas y unidades territoriales representadas. No son cifras escritas manualmente.
- El relleno por pais aplica un degradado continuo por coordenada vertical, con el ecuador como zona mas oscura. Se normaliza el valor del color previo para evitar heredar el oscurecimiento por centroide de 0.1.6.
- Chukotka recibe color de Asia mediante una correccion en tiempo de carga.
- La escena alternativa mapa_principal_v0.1.7.tscn apunta al script correcto MapaPrincipal_v0.1.7.gd. Esto evita la referencia rota a gdscripts.gd de la escena 0.1.6.
- Se incluye herramientas/construir_mapa_v0.1.7.py para que las regeneraciones futuras partan de colores base sin centroide y asignen Chukotka a Asia.

LIMITACIONES PENDIENTES
- El rediseño topologico completo de fronteras no esta terminado. Se conserva la malla de bordes de la fuente actual; el codigo todavia necesita una pasada de validacion visual para eliminar cortes y huecos sin crear fronteras falsas.
- El aumento de provincias administrativas de todos los paises tampoco esta incluido. La fuente actual representa 480 unidades territoriales y 177 paises/soberanias, pero no contiene subdivisiones oficiales suficientes para todos. No se inventaron divisiones. Para completarlo hay que integrar una fuente administrativa global de nivel 1, validar cobertura y correspondencia por pais, revisar licencia y regenerar las mallas.
- No se pudo ejecutar Godot en este entorno para hacer una prueba de arranque/FPS. Esta es una compilacion de desarrollo y debe probarse localmente antes de considerarse version estable.

GENERADOR
Desde la carpeta del proyecto:
python3 herramientas/construir_mapa_v0.1.7.py

Requiere Python 3, numpy, scipy y pillow.
La regeneracion sobrescribe archivos dentro de datos/. Haz una copia de seguridad antes de ejecutarla.
